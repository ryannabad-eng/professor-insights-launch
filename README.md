# Professor Insights

Professor Insights is a Chrome extension that helps students see professor ratings and review information while looking at class registration options.

## Features

- Detects professor names on supported class registration pages
- Shows available professor ratings and review information
- Lets students manually search for a professor
- Lets students save favorite professors into albums
- Provides Quick Rate links to Rate My Professors
- Uses PolyRatings information for Cal Poly professors
- Lets students choose their school when searching for professors outside Cal Poly

## Install from the Chrome Web Store

1. Visit the [Professor Insights Chrome Web Store page](Chrome Web Store link).
2. Click **Add to Chrome**.
3. Click **Add extension** when Chrome asks for confirmation.
4. Open a class registration page and click the Professor Insights icon in the Chrome toolbar.

## How to Use

1. Open your class registration or class-search page.
2. Click the Professor Insights extension icon.
3. Review detected professor names, ratings, and available review information.
4. Use the search bar if a professor is not detected automatically.
5. Select **Save** to add a professor to an album and view them later.
6. Select **Quick Rate** to open a matching Rate My Professors page or a safe manual-search link.

## Local ZIP Testing

The downloadable ZIP is included for local testing.

1. Download and unzip `professor-insights-v0.8.0.zip`.
2. Open Chrome and go to `chrome://extensions`.
3. Turn on **Developer mode**.
4. Click **Load unpacked**.
5. Select the unzipped `professor-insights-v0.8.0` folder.

## Data and Limitations

Professor ratings are community-submitted and should be used as one part of a student’s class-registration decision. Available professor information can change as review sources and registration websites update.

Professor Insights does not submit ratings or store Rate My Professors login information. Quick Rate only helps students open the appropriate page, and students choose whether to submit anything.
